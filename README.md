## Админка Charteri

Панель для сотрудников Charteri. Связана с кабинетом и сайтом: все три демо видят
данные друг друга в одном браузере, поэтому показывать удобно в соседних вкладках.

| Раздел | Что показывает |
|---|---|
| Обзор | задачи на сейчас, запросы на подтверждение, доход от сбора по дням, продажи, деньги на балансах агентств |
| Задачи | одна очередь: запросы коллег на подтверждение, цена по заявке на самолёт или вертолёт, пополнения наличными и переводом, новые агентства, просьбы пассажиров сайта, возвраты к зачислению |
| Подтверждения | критичные операции ждут второго сотрудника: крупные возвраты, ручные изменения баланса, сбор и наценка, роли и права, новые сотрудники, удаление направлений. Подтвердить, отклонить с причиной, отозвать свой запрос; история решений; правила (что и от какой суммы подтверждать) меняет основатель |
| Заказы | все заказы агентств и сайта; назначить цену, подтвердить у поставщика, отменить со штрафом |
| Агентства | баланс и оборот, заявки на подключение, блокировка с причиной, корректировка баланса |
| Пассажиры сайта | покупатели по телефону, их заказы |
| Деньги | пополнения, общая выписка, доход от сбора, возвраты, выгрузка CSV |
| Цены | сервисный сбор и наценка на авиабилеты — сайт и кабинет пересчитывают сразу |
| Направления | добавить направление (код, названия на трёх языках, координаты, тариф, курорт с отелями) — оно сразу появляется в поиске, на карте, в турах и отелях сайта и кабинета; скрыть, удалить |
| Интеграции | какие сервисы на тестовых данных и какие ключи нужны |
| Сотрудники | карточка: имя, телефон, почта, должность, отдел, роль, доступ; журнал каждого сотрудника |
| Роли и права | 11 ролей из ТЗ и свои роли; таблица прав: раздел × действие (просмотр, создание, изменение, удаление, подтверждение, отмена, возврат, выгрузка, управление) |
| Журнал | кто, в какой роли, что, когда, IP и устройство, было → стало; фильтры по сотруднику, разделу, периоду; выгрузка CSV |

Роли из ТЗ: основатель системы, владелец системы, системный администратор,
финансовый менеджер, менеджеры B2B, B2C, по продажам, операционный,
контент-менеджер, менеджер поддержки, наблюдатель / аналитик. В демо у каждой роли
свой сотрудник, переключаются сверху. Основатель — Ammar Temurov
(+998 90 000 00 05): у него все права, он создаёт роли и меняет их права, его
действия выполняются без второго подтверждения. Свои права менять нельзя;
основателя и владельца назначает только основатель; дать роли можно только те
права, которые есть у тебя самого. В демо IP в журнале условный: настоящий адрес
записывает сервер.

Сотрудник может ещё создать агентство вручную, поправить его реквизиты и написать
агентству сообщение — оно придёт в колокольчик кабинета.
Пока админка открыта, кабинет и сайт не отвечают за оператора сами: цену чартера,
пополнения и возвраты подтверждает сотрудник. Закрыли админку — через минуту-две
демо снова отвечает само.

Для показа: откройте кабинет и админку рядом. В кабинете попросите пополнить
баланс наличными — в админке появится задача кассиру; подтвердите — баланс агента
вырастет. Заявка на вертолёт из кабинета ждёт цену от оператора.

Подтверждение вторым сотрудником: войдите как Dilnoza (владелец) и поменяйте сбор
в «Ценах» — изменение уйдёт на подтверждение. Переключитесь на Ammar — запрос
ждёт в «Подтверждениях»; подтвердите — сайт и кабинет пересчитают цены.

## Кабинет агентства

Тот же дизайн и те же пять услуг, что на сайте, но для турагентства: агент
бронирует для своих клиентов и платит с баланса агентства.

| Раздел | Что показывает |
|---|---|
| Обзор | поездки клиентов на живой карте, баланс, что ждёт решения, лента событий |
| Бронирование | пять форм поиска и табло вылетов; «бронь для клиента» подставляет его паспорт |
| Оформление | путешественники из базы клиентов, сервисный сбор 3% отдельной строкой до оплаты, остаток после списания; не хватает денег — оплата выключена |
| Заказы | фильтры по статусу и услуге, поиск; карточка заказа с документом, историей, оплатой чартера и отменой |
| Отмена | штраф поставщика по правилам услуги, сбор не возвращается, остаток приходит на баланс |
| Баланс | пополнение картой (сразу), переводом или наличными (после подтверждения, в демо — 8 секунд); выписка с остатком после каждой проводки, выгрузка CSV |
| Клиенты | паспорта и телефоны, заказы клиента |
| Брендирование | логотип, цвет, название и контакты агентства на билетах и ваучерах; образец меняется при вводе |

Для показа: в демо-агентстве уже есть заказы во всех статусах. Заявка на
вертолёт получает цену через 5 секунд после входа, пополнение наличными
зачисляется через 8 секунд.

## Сайт для пассажиров: пять модулей

| Модуль | Путь | Данные |
|---|---|---|
| Авиабилеты | поиск → календарь цен → фильтры → пассажиры → оплата → посадочные талоны с QR | движок мобильного приложения |
| Туры | направление, ночи, туристы → пакет «перелёт + отель + трансфер», −7% → турваучер | движок + каталог отелей |
| Отели | город, даты, гости → звёзды, питание, цена → номер → ваучер | тестовый каталог |
| Частные самолёты | маршрут, класс борта → оценка → заявка → цена от менеджера → оплата → ваучер | расчёт по расстоянию |
| Вертолёты | Чимган, Амирсой, Чарвак, Заамин, Самарканд, обзорный полёт | расчёт по расстоянию |

Для показа: на рейсах в **Анталию** перед оплатой срабатывает экран «Цена изменилась».
По заявке на частный самолёт или вертолёт «менеджер» присылает цену через 5 секунд.

Названия отелей вымышлены намеренно: реальные создали бы впечатление подписанных договоров.

## Как устроен код

Исходники — в `site-src/`, по файлу на модуль. Сайт и кабинет собираются из
общих модулей (`js/`); у кабинета свои страницы и оформление (`b2b/`). На
GitHub Pages уходят три собранных файла: `index.html` (кабинет),
`b2c/index.html` (сайт) и `admin/index.html` (админка — страницы в `admin/`).

    cd site-src
    python3 gen_data.py      # взять маршруты, аэропорты и тексты из ~/charteri-mobile
    python3 build.py         # собрать все три; python3 build.py admin — только админку

`build.py` перед сборкой проверяет, что у каждого ключа строки в коде есть
перевод, и не соберёт сайт с сырым ключом вместо текста.
