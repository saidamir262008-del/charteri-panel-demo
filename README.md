# Charteri — демонстрация кабинета агента

Одностраничный рабочий прототип B2B-панели. Открывается в любом браузере,
ничего не требует, данные живут в браузере посетителя.

**Адрес:** https://saidamir262008-del.github.io/charteri-panel-demo/
**Код входа в демонстрации:** 0000

## Что работает по-настоящему

Расчёт сервисного сбора 3% с округлением вверх, списание с баланса агентства
с блокировкой при нехватке средств, переходы статусов заказа, возврат за
вычетом штрафа поставщика с удержанием сбора, брендированный ваучер.

## Что здесь не настоящее

Вход демонстрационный: код проверяется в браузере и написан прямо на экране.
Билеты, туры и отели помечены «скоро» — ждут интеграций. Данные не уходят
на сервер и сбрасываются кнопкой «Сбросить демо».
