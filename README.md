# Charteri — демонстрации B2B и B2C

Одностраничный рабочий прототип B2B-панели. Открывается в любом браузере,
ничего не требует, данные живут в браузере посетителя.

| | Адрес | Вход |
|---|---|---|
| Кабинет агентства (B2B) | https://saidamir262008-del.github.io/charteri-panel-demo/ | код 0000 |
| Приложение пассажира (B2C) | https://saidamir262008-del.github.io/charteri-panel-demo/b2c/ | любые 4 цифры или «Продолжить как гость» |

## B2C: что перенесено из мобильного приложения

Строки на трёх языках, таблица маршрутов, перевозчики, аэропорты и поисковый
движок взяты из исходников charteri-mobile генератором, а не перепечатаны —
демо показывает те же рейсы, что приложение, на тех же маршрутах и датах.

Экран «Цена изменилась» срабатывает на маршруте в Анталию (AYT) — его можно
показать по заказу.

## Что работает по-настоящему

Расчёт сервисного сбора 3% с округлением вверх, списание с баланса агентства
с блокировкой при нехватке средств, переходы статусов заказа, возврат за
вычетом штрафа поставщика с удержанием сбора, брендированный ваучер.

## Что здесь не настоящее

Вход демонстрационный: код проверяется в браузере и написан прямо на экране.
Билеты, туры и отели помечены «скоро» — ждут интеграций. Данные не уходят
на сервер и сбрасываются кнопкой «Сбросить демо».
